PocketDesk for Android

Download the APK

Android 11 or newer. New here? What PocketDesk is and how it works.

On the phone (once)

  1. Install the APK. Your browser will ask to allow installing apps from it.
  2. Turn on Developer options: Settings → About phone → tap Build number seven times.
  3. Open PocketDesk. Under Desktop helper tap Pair: Wireless debugging opens. Turn it on, tap Pair device with pairing code, pull down the notification shade and type the code into the PocketDesk notification.
  4. Under Desktop windows tap Turn on, then restart the phone once.
  5. Under Advanced, Allow background, so the helper can start after a restart.

On the screen

  1. Open pocketdesk.outsmartis.dev in Chrome, Edge or Safari on the laptop, mini PC or TV.
  2. Type the 6-digit code from the phone app (first time only).
  3. Click into the desktop to type there. Full screen: the button on the taskbar or F11.

Shortcuts

  • Windows key: app menu (type to search, Enter to open).
  • Esc: Back. Ctrl+V: paste the computer's clipboard.
  • Drag a window's top bar to move it, its edges to resize; the taskbar buttons switch and close windows.
